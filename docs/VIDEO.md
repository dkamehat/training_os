# M12 映像解析モジュール — 観る目を持つ自動トレーナー

**あなたがやること: トップセットを撮ってDriveフォルダに放り込む。それだけ。**
分析・記録・メニュー反映・成長トラッキングは全部OSがやる（負荷バジェット追加ゼロ）。

## パイプライン

```
スマホで撮影 → Drive「TrainingOS_videos」へアップ（2タップ）
   → 日曜レビュー時にOSが自動検知
   → ffmpegでフレーム抽出（開始/ボトム/ミッド/ロックアウトの4-8枚）
   → Claude視覚分析（種目別チェックリスト＋過去分析との比較）
   → 🎥フォーム分析DBに記録（スコア・主要指摘1つ・次回キュー1言）
   → 次週メニューへ反映（P-02: キュー変更・重量判断・種目変更）
```

- Driveフォルダ: https://drive.google.com/drive/folders/1AGktVbxcec4WqBPkFDPf9gV0MPow_X8O
- 記録先: Notion「🎥 フォーム分析」DB（collection://7e81e693-d381-4d91-9180-cb19d698e62d）
- 実行プロンプト: `prompts/P-07_form-analysis.md`（週次Routineのステップ④として自動実行。急ぎのときは「動画見て」とこの会話に投げれば即時分析）

## 撮影プロトコル（質の高いFBはここで決まる）

| 項目 | 指定 |
|---|---|
| 対象 | **トップセットのみ**（全セット撮影は不要。編集もトリミングも不要） |
| アングル | SQ/DL=**正面**（左右差検出優先）、余裕があれば斜め45°を隔週交互。BP=**足側斜めor横** |
| 画角 | 全身＋バーが常に入る。縦置き・胸〜腰の高さ |
| ファイル名 | `MMDD_種目_重量.mp4`（例: `0823_SQ_152.5.mp4`）— これだけ守るとDB記録が完全自動になる |

## 種目別チェックリスト（分析の観点・エビデンスベース）

- **SQ**: ①深さ（股関節がひざ下） ②左右対称（バー傾き・骨盤シフト・右膝の内外） ③バーパス（ミッドフット直上の垂直性） ④つま先角と膝のトラッキング ⑤ボトムでの腰椎ニュートラル（バットウィンク）
- **BP**: ①肩甲骨パッキングの左右対称（右傾斜の既往を重点） ②バー接地点の一貫性 ③手首-肘の垂直性 ④ブリッジ・脚の使い方 ⑤バーパス（Jカーブ）
- **DL**: ①セットアップ（バーとミッドフット距離・肩とバーの位置関係） ②スラック抜きと左右の踏圧（右足偏りの既往を重点） ③腰椎ニュートラル維持 ④バーの体接触 ⑤ロックアウト（過伸展しない）
- 共通: 呼吸/ブレースのタイミング（可能な範囲）・既往フラグ（右側非対称・肩）を毎回確認

## 成長記録（フォームのPRを作る）

- 各分析はDBに1行=時系列でスコアが並ぶ → **「重量が増えてもスコアが落ちない」ことがフォームの成長**の定義。
- 月1回: 同種目の最古vs最新フレームを並べて比較＋Will Ball（同体型ロールモデル）の同ポジションとの差分をWillBall比較欄に記録。
- 週次ダイジェストに「フォームスコア」行を追加（分析があった週のみ表示）。左右対称が「要注意」2回連続でPT受診提案（M3連携）。

## メニューへの反映規則（P-02連携）

| 分析結果 | 次週への反映 |
|---|---|
| スコア4-5・指摘なし | プログレッション規則どおり進行 |
| スコア3 or 要修正1つ | 重量進行は維持、該当Dayの重点キューを差し替え |
| スコア1-2 or 左右対称「要注意」 | 該当種目は重量据え置き＋テクニック枠でキュー練習を追加 |
| 痛みを示唆する動作（かばい・途中で止まる） | 重量-5%＋本人に質問（自動進行しない） |

## 制約（正直に）

- 動画から**バー速度の正確な計測はしない**（フレーム目視では精度が出ない。VBTはアプリ計測が正）。
- 判定は定性評価。関節角度の厳密な数値化はしない——「前回の自分」との比較を最重視することで精度を担保する。
- 大容量動画はフレーム抽出後に破棄（コンテナはエフェメラル）。原本はDriveが正。
