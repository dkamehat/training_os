## 個別レビューの主要findings（採用分）

### ① S&Cコーチ
- 伸び幅配分の目安: **S 210→235 / B 162.5→185 / D 245→265 = 685kg**（12ヶ月の野心的ライン）。BPの伸び代が最大。
- 強度%とRPEの二重指定は矛盾 → RPE主導＋%はガイドに一本化。
- プログレッション規則（翌週+2.5kgの根拠）が未仕様 → M1に明文化。
- Yellow時の対応は原因別分岐（睡眠起因→重量維持セット減 / 痛み起因→種目変更）。
- 左右非対称の定量化（バー傾き角度・片脚種目の左右レップ差を月次KPI）。
- 足首: ヒールエレベートをSQ標準仕様に固定、カーフ荷重ストレッチ追加、膝壁テスト隔週。
- n=1のA/B実験プロトコルをM1に正式仕様化。

### ② SNSグロース
- チャネル別頻度の定義（X日次 / IGリール週3 / note週1）。週1バッチで日次分を事前生成＋予約投稿すればトークン効率と両立。
- 動画パイプライン未設計はIG破綻要因 → CapCutテンプレ等で編集を定型化。
- **女性層**: 「回復と続ける技術」「増量物語の翻訳（食べて強くなる）」「5分ドリル習慣」「日常ストーリーズ」が刺さる軸。
- **男性リフター層**: 界隈エンゲージメント枠（週3×15分）、失敗ログの正式コンテンツ化、Will Ball比較のリール/記事化、大会カウントダウンのドラマ化、プロフィールに数字明示。
- CBum美学: ビジュアルテンプレ統一＋5分ドリル連続日数カウント＋データの美しいビジュアライズ。
- 投稿成績→翌週フック調整の分析ループ（コンテンツ側のオートレギュレーション）。

### ③ 収益性
- P1目標達成の現実的タイムラインは18-24ヶ月。フェーズ移行は時間でなくマイルストーンゲートで。
- **オンラインコーチング/フォームチェックが年30万円への最短ルート**（クライアント2-3人で達成）→ P1に追加。
- YouTube（長尺+Shorts）をP2検討対象に明記。メールリスト/販路分散でプラットフォーム依存を低減。
- P3（本業接続）は18ヶ月待たず、repo構築過程を今からBizOps/AI発信のポートフォリオ化。
- ステマ規制のPR表記ルール、発信時間キャップを明文化。

### ④ スポーツ科学
- ボリュームランドマーク10-20セットは「出発点ヒューリスティック」に格下げ（Pelland 2024等）。「頻度より総ボリューム」は肥大の知見で、筋力には頻度・特異的練習が効く——適用先の混同を修正。
- 増量は**+200-350kcal / +0.1-0.25%BW/週**へ下方修正、体重判定は7日移動平均。
- **Proximity to failure**（Robinson 2024）: 筋力種目はRIR2-4で疲労節約、肥大アクセサリーのみ失敗近接 → 疲労体質への核心原則としてM1に採用。
- **Lengthened partials / 長筋長重視**をアクセサリー設計に導入。
- **Velocity loss 10-20%打ち切り**をメインワークに導入。
- 予定deload vs 反応的deload（Coleman 2024）: 反応的トリガーを主に。
- 睡眠延長（高強度日前+1-2h）の介入エビデンスをM5に。
- claims.mdスキーマ改修: エビデンスレベル・対象集団・効果量・**反証欄**・changelog必須。二次発信者は一次情報源ではない——**必ずDOIまで遡る**。AI出典はDOI実在確認を通す。
- ビタミンD（欠乏時のみ）・マグネシウム（弱）の確信度を下方修正。Zone2有酸素を設計に明記。

### ⑤ 敵対的レッドチーム
- 最頻失敗シナリオ: (1)週次バッチの静かな崩壊 (2)増量×疲労×週5化による腰肩の故障 (3)発信タスクの複利的負債化。
- 「疲労管理が心臓部」と「1年+102.5kg」は原理的に矛盾 → 二段階目標＋判定ゲートで決断を構造化（先送りしない）。
- 着地体重の不整合（90-91kg vs 93kg級）→ 統一: 12ヶ月で90-91kg、93kg級はノーカットで出場可（上限93.0）。
- Readinessのゲーミング可能性、AI出力の検証プロセス欠如、AIサブスク費のコスト計上漏れ → M11ガバナンスで対応。
- 「Technique枠は疲労コストほぼゼロ」等の無出典断定 → claims.md登録対象に。
