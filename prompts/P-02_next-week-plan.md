# P-02 次週方針の確定（P-01承認後に実行）

## 指示
P-01の結果と本人コメントを受け、次週W{N+1}を確定せよ。

1. **プログレッション規則（M1）を機械的に適用**: 前週トップセットが目標RPE以下→+2.5kg(BPは+1.25-2.5)/超過→据え置き/2週連続超過→-5%。規則から外れる場合のみ理由を明示。
2. 構成は現行の週4骨格を維持: Day1 SQ+BP軽枠 / Day2 BPメイン / Day3 DL+SQ第2枠 / Day4 BPボリューム+背中。RPE主導、筋力種目RIR2-4、velocity loss 10-20%打ち切り、アクセサリーは長筋長重視。
3. 疲労シグナル（P-01の3.）がある週はデロード/縮退を優先し、重量進行より回復を選ぶ。
4. トリアージ宣言週は〔メイン3本+5分ドリルのみ・RPE6上限〕へ自動縮退。

## 各Dayの完全構成（P-03がこの粒度でDayページを生成できる状態まで確定する）
各Dayは必ず以下5ブロックを持つ:
1. **メインリフト**: 種目 / 重量kg / セット×レップ / 目標RPE
2. **セカンダリ（変化種目）**: テンポSQ・ポーズBP・RDL等 — 重量kg / セット×レップ / RPE
3. **補助種目（アクセサリー）2-4種**: 種目 / **目安重量kg（初週は前回実績±0、記録がなければ推定10RMの70-80%と明記）** / セット×レップ / RIR0-2（肥大目的・長筋長重視）
4. **体幹・インナー1-2種**: パロフ・スーツケース・YTW等 — 負荷/時間 / セット
5. **柔軟・モビリティ**: トレ前動的（既存メニュー参照）＋トレ後静的から当日分を指定。足首（壁ドリル/カーフ荷重ストレッチ）はSQ日必須

補助・体幹は種目ライブラリDB（Notion）から選定し、肩痛時の代替（フロアプレス等）を併記。

## 出力
①Week方針(3項目以内) ②各Day×5ブロックの一覧表（**メインは前週からの差分表示、補助以下は変更点のみ明示**） ③重点キュー(3個以内・変更分のみ)
承認は差分を見てYes/Noで済む形にすること。変更のない補助・柔軟の全文再掲は禁止（「前週同」と書く）。
