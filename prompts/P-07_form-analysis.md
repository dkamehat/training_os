# P-07 フォーム映像分析（週次Routineステップ④ / オンデマンド「動画見て」でも起動）

## 手順
1. 環境準備: `which ffmpeg || apt-get update -qq && apt-get install -y ffmpeg -qq`（コンテナはエフェメラルなので毎回確認）。
2. Drive検索: `parentId = '1AGktVbxcec4WqBPkFDPf9gV0MPow_X8O' and mimeType contains 'video/'` で前回分析以降（フォーム分析DBの最新日付以降）の新規動画を検出。なければこのステップをスキップ（報告に「新規動画なし」と1行）。
3. 各動画: download_file_content(base64)→scratchpadに保存→ffprobeで長さ確認→フレーム抽出:
   `ffmpeg -i in.mp4 -vf "select='not(mod(n,N))',scale=720:-1" -vsync vfr f_%02d.jpg`（レップの開始/ボトム/ミッド/ロックアウトを含む4-8枚になるようNを調整。1レップ目と最終レップを優先）
4. Readでフレームを視覚分析。観点はdocs/VIDEO.mdの種目別チェックリスト＋既往フラグ（右側非対称・肩・右足偏り）。**必ず同種目の直近の分析行と比較**（改善/悪化/同じ）。
5. 🎥フォーム分析DB（collection://7e81e693-d381-4d91-9180-cb19d698e62d）に1行作成: ファイル名から動画/日付/種目/重量kgを解析、総合スコア1-5、左右対称/深さ・接地/バーパス、主要指摘（**1つだけ**）、次回キュー（**一言だけ**）、Driveリンク、Week。
6. docs/VIDEO.mdの反映規則に従いP-02の次週生成に反映（キュー差し替え/据え置き/テクニック枠追加/-5%＋質問）。
7. 報告はダイジェスト内に1-2行（例: 「🎥SQ152.5: スコア4、右膝わずかに内→次回キュー『右膝を三趾へ』」）。

## 制約
- 指摘は最重要1つに絞る（列挙しない。直すのは一度に一つ）。
- 褒めも1つ入れる（前回比の改善点。成長記録の意義）。
- バー速度の数値は主張しない。痛み示唆の動作を見たら自動進行を止め blocking質問。
