# Training OS — kame_lift

**93kg級パワーリフター × AI × 発信 を1つのシステムとして運用するOS。**

現状: 体重85-86kg / S210 B162.5 D245 (Total 617.5) → 目標: 93kg級で戦える身体とトータル。
技術面ロールモデル: Will Ball（体型類似）。リスペクト: Chris Bumstead（発信・ブランド哲学）。

## このリポジトリの役割

- **GitHub（このrepo）** = OSの頭脳。設計・原則・知識ベース・プロンプト/スキル・自動化の定義。
- **Notion（ライフOS / PJ2）** = 運用データの正（トレーニングログDB・デイリーログDB・現在のプログラム・Dayページ）。
- **Claude** = エンジン。週次SOPでプログラム生成・疲労調整・コンテンツ生成を実行。

全体設計は [`docs/DESIGN.md`](docs/DESIGN.md) を参照。

## 運用原則

1. **Single Source of Truth** — データはNotion、思想と手順はこのrepo。重複させない。
2. **トークン効率** — 週次バッチ運用。定型プロンプト＋差分更新。日次はログ入力のみでAI不要。
3. **感覚のフロア** — 最終判断はAIに委ねない。痛み・違和感のフロアは本人が持つ。
4. **エビデンスファースト** — 推奨は必ず知識ベース（M9）の出典に紐づける。
